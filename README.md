# Mengzhe Geng — Academic Website

This repository contains the Jekyll source for Mengzhe Geng’s academic website.

The site uses the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template. Its theme license and notice are in [LICENSE](LICENSE).

To preview locally, install the gems listed in `Gemfile` and run `bundle exec jekyll serve`. The site is configured for `https://mengzhegeng.github.io`.
